# prairie-smarttv

Prairie client for Samsung Tizen and LG webOS televisions.

**Status:** placeholder. This app is **Phase 4** of the Prairie roadmap and will be built after the Phase 3 UI/UX redesign so the TV surface matches the new design system.

## Planned shape

- Shared remote-first web codebase packaged for Tizen (`.wgt`) and webOS (`.ipk`)
- Native video pipelines per platform (Tizen AVPlay / webOS Starfish-style)
- Talks to Prairie over `/api/v1` (not a Jellyfin-primary client)

## Related

- Server source (AGPL): https://github.com/prairie-server/prairie-server
- Android / Apple clients ship earlier; Fire TV is covered by the Android TV app
